# Evaluación II - Programación Web

Requisito: tener Node.js 18 o superior instalado.

## Cómo ejecutar

Cada ejercicio necesita dos terminales abiertas en la raíz del repositorio:
una para el backend y otra para el frontend.

### Ejercicio 1: Adivina el número

Terminal 1 (backend, puerto 3000):
```bash
cd ejercicio-1-adivina-numero/backend
npm install
npm start
```

Terminal 2 (frontend):
```bash
cd ejercicio-1-adivina-numero/frontend
npm install
npm run dev
```

### Ejercicio 2: Food DEI

Terminal 1 (backend, puerto 3001):
```bash
cd ejercicio-2-food-dei/backend
npm install 
npm start
```

Terminal 2 (frontend):
```bash
cd ejercicio-2-food-dei/frontend
npm install
npm run dev
```

Abrir en el navegador la dirección que muestre Vite (normalmente http://localhost:5173).

Para correr el otro ejercicio, detener primero el actual con Ctrl + C.
